## 🚀 Quick Start

### Prerequisites
Make sure you have Python 3.8+ installed. Check with:
```bash
python --version
```

### Installation

```bash
# Clone this repository
git clone https://github.com/YOUR_USERNAME/shadowfox-dataviz-internship.git
cd shadowfox-dataviz-internship

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter Notebook
jupyter notebook
```

Then open `notebooks/visualization_guide.ipynb` and run the cells!

## 🌟 Key Takeaways

| Library | Best For |
|---------|---------|
| **Matplotlib** | Full customization, scientific charts, complex layouts |
| **Seaborn** | Quick EDA, statistical plots, beautiful defaults |

> **For beginners: Start with Seaborn for beautiful results fast, then learn Matplotlib for full control!**
